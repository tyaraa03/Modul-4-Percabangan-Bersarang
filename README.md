# Modul-4-Percabangan-Bersarang
Percabangan bersarang atau nested if adalah percabangan yang di dalamnya terdapat percabangan lain. Dengan nested if, kita bisa memeriksa beberapa kondisi secara bertahap. Jadi, kita mengecek kondisi pertama terlebih dahulu, lalu lanjut ke kondisi berikutnya jika syaratnya terpenuhi.
